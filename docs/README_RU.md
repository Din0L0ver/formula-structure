# formula-structure — краткое описание

`formula-structure` — исследовательская Python-библиотека для восстановления
компактных интерпретируемых формул по табличным результатам закрытого
калькулятора или симулятора.

Библиотека решает задачу в несколько этапов:

1. ищет области, внутри которых действуют разные локальные формулы;
2. оценивает форму влияния каждого признака с помощью ALE;
3. проверяет парные взаимодействия сплайновыми моделями и кросс-валидацией;
4. строит ограниченный граф допустимых математических модулей;
5. оптимизирует степени и сдвиги через Optuna либо выбирает функции из
   расширенного словаря;
6. для фиксированных модулей точно находит коэффициенты, минимизирующие MAPE,
   как решение weighted LAD.

Библиотека не утверждает, что найденная зависимость является истинным
физическим законом. Она формирует проверяемую структурную гипотезу и оценивает
её на отложенных данных.

## Два варианта итоговой модели

### Степенной граф + Optuna

Для каждого признака используется одна форма

```text
((x + shift) / scale) ** alpha.
```

Optuna подбирает степени и небольшие сдвиги. Граф ограничивает разрешённые
произведения признаков.

### Расширенный граф + weighted LAD

Для каждой вершины создаются кандидаты `x`, `sqrt(x)`, `x^2` и степень,
предложенная анализом ALE. Для подтверждённых рёбер создаются произведения.
Модули последовательно отбираются по out-of-fold MAPE, после чего коэффициенты
полной формулы находятся прямой оптимизацией weighted LAD.

Слово «точная» относится только к оптимизации коэффициентов при уже выбранной
структуре. Сам поиск структуры остаётся жадным.
